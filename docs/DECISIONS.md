# 技术与设计决策记录（DECISIONS）

## D-001 技术栈：Vite + TypeScript + DOM

- **日期**：2026-07-23
- **决策**：使用 Vite 构建、TypeScript 编写、DOM/CSS 呈现 UI；核心规则纯 TS 模块。
- **原因**：环境已具备 Node；测试友好；演示成本低；适合文艺 2D UI 游戏。
- **备选**：Phaser、PixiJS、Godot HTML5 导出——增加依赖与学习成本，初期不必要。
- **后果**：复杂粒子/物理需自研或后续引入轻量库。

## D-002 游戏类型：情绪流通经营

- **日期**：2026-07-23
- **决策**：不做成战斗 RPG，而做「温柔瞬间」情绪流通小店。
- **原因**：对齐用户给定概念；差异化强；适合毕业设计叙事与系统设计展示。

## D-003 逻辑与 UI 分离

- **日期**：2026-07-23
- **决策**：`src/core` 无 DOM 依赖；`src/ui` 只负责渲染与输入。
- **原因**：单元测试可直接驱动真实规则；避免“测试剧场”。

## D-004 程序化音效优先于外部音频包

- **日期**：2026-07-23
- **决策**：使用 Web Audio 振荡器 + tone 表；设置 sfxEnabled；减少动效时静音。
- **原因**：环境无合法商用 SFX 包；避免版权风险；可测。
- **后果**：尚无 BGM 循环；T0039 可后续替换为真实文件播放器。

## D-006 原创合成 WAV + HybridAudioBus（2026-07-23）

- **决策**：用脚本生成 mono 22.05kHz WAV（无第三方采样）；`HybridAudioBus` 优先文件，回退 `ProceduralAudioBus` tone；BGM 用 HTMLAudioElement 循环。
- **理由**：T0039 验收要有合法可再分发资源；合成可复现、无版权风险。
- **后果**：氛围偏「占位级」短循环；日后可同 id 替换为人声/CC0 长曲。

## D-007 M2 当日委托订单（2026-07-23）

- **决策**：`ShopOrder` 按日确定性 roll；赠予或货架售出匹配形态/最低品质时履约；不阻断核心循环。
- **理由**：毕业演示需「系统感」第二循环，且纯函数可测。
- **后果**：同日同 salt 订单固定；UI 高亮 preferredVessel。
