## M1–M12 框架（0021–1000）

后续轮次在执行中按 backlog 动态展开；保持每轮 20–40 分钟粒度。

### 0021–0100 核心玩法

配方解锁、失败宽容反馈、连击温存、客人好感、多种流通方式（上架/赠予/搁置）、教程第一日。

### 0101–0200 主要系统

库存上限、货架陈列、定价（温情价）、随机事件、天气氛围、成就草稿。

### 0201–0320 内容管线

多日剧本、特殊客人、Boss 情绪（高难度匹配）、内容 JSON schema、校验脚本。

### 0321–0420 UI/UX

完整 HUD、键盘导航、焦点环、字号、减少动效、色盲友好形态区分。

### 0421–0540 视觉

角色立绘、店装、图标替换、品质特效、过场。

### 0541–0620 音频

BGM 循环、UI 点击、转化成功/失败音、混音总线。

### 0621–0720 数据工具

存档版本迁移、调试面板、平衡配置表。

### 0721–0820 测试

规则属性测试、回归集、视觉快照（若环境允许）。

### 0821–0900 性能

打包体积、首屏、长时运行泄漏检查。

### 0901–0960 打磨

文案、难度曲线、空状态、错误提示。

### 0961–0990 发布

演示脚本、答辩大纲、构建产物说明。

### 0991–1000 冻结

清单验收、tag 候选、归档。
