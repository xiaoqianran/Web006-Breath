# 演示脚本（约 5–8 分钟）

适用：毕业设计中期/答辩演示。

## 0. 开场（30s）

- 一句话：经营「情绪流通」小店，把小心情变成花茶画乐物。
- 打开 `npm run dev` 或 `npm run preview`。

## 1. 主菜单（20s）

- 展示主菜单插画与店名「一息」。
- 点「关于」说明主题 → 返回 →「开始今日经营」。

## 2. 教程（20s）

- 若首次：展示三步教程（接待 / 转化 / 流通）。

## 3. 完整一次流通（90s）

1. 接待下一位，朗读客人原文。
2. 解释标签与形态相性（可开气息提示）。
3. 选择匹配形态 → 展示品质与匹配分。
4. 选择「赠予」或「上架」→ 瞬间卡片与温存。

## 4. 系统展示（90s）

- HUD：日、温存、口碑、今日流通目标。
- 再完成 1–2 次流通；打开「瞬间图鉴」。
- 设置：关闭提示 / 减少动效。
- 刷新页面，「继续经营」恢复进度。

## 5. 技术亮点（60s）

- `src/core` 纯逻辑可测；`npm test` 展示通过数。
- 架构分层：规则 / UI / 数据分离。
- 匹配算法与 GDD 一致。

## 5.5 快捷键与帮助（20s）

- 按 `?` 展示帮助层；`Esc` 关闭。
- 演示 1–5 选形态。

## 6. 收尾（30s）


- 创新点：情绪作为可流通资源。
- 后续：多日剧本、音频、完整视觉替换。
- Q&A。

## 备用路径

- 若 dev server 不可用：打开 `dist/index.html` 经 `npm run preview`。
- 若浏览器限制 localStorage：演示核心循环仍可当场完成。
