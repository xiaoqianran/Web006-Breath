# 项目假设（ASSUMPTIONS）

本文档记录自治开发中的可逆假设。若后续决策推翻假设，须同步更新 `docs/DECISIONS.md`。

## A-001 游戏主题

- **内容**：玩家经营「温柔瞬间」情绪流通小店「一息」。
- **依据**：用户会话中给出的店概念（收集小情绪/小故事 → 变为花/茶/画/音乐/小物件再流通）。
- **状态**：已采纳。

## A-002 技术栈

- **内容**：TypeScript + Vite + 原生 DOM UI；纯逻辑与渲染分离；Vitest 单元测试。
- **理由**：当前环境已有 Node 24；无需 Unity/Godot 安装；便于毕业设计浏览器演示与自动化测试。
- **状态**：已采纳。

## A-003 核心玩法循环

1. 接待客人（或读取投递的情绪纸条）
2. 识别情绪标签（如：想念、释然、疲惫、悸动、遗憾）
3. 选择容器形态：花 / 茶 / 画 / 音乐 / 小物件
4. 进行「转化」（匹配度决定品质与流通价值）
5. 上架或赠予，完成一次情绪流通
6. 获得温存值（Warmth）与口碑，解锁新客人与配方

- **状态**：已采纳，实现以纯函数状态机为准。

## A-004 目标平台

- 桌面浏览器（Chrome/Firefox/Edge 近两年版本）
- 分辨率目标：1280×720 及以上；UI 可缩放

## A-005 语言

- 代码标识符：英文
- 提交信息：中文 Conventional Commits
