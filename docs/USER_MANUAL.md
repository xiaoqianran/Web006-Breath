# 用户操作手册

## 运行

```bash
npm install
npm run dev
```

浏览器打开提示地址。生产预览：

```bash
npm run build && npm run preview
```

## 怎么玩

1. 主菜单「开始今日经营」（首次会显示教程）。
2. 在接待处点「接待下一位」或按 **Enter**。
3. 阅读客人的话与标签，选择容器形态（或按 **1–5**）。
4. 转化完成后选择「上架」或「赠予」。
5. 查看瞬间卡片与温存；继续接待。
6. 达到今日目标后可打烊并进入下一日。

## 菜单功能

| 入口 | 作用 |
|------|------|
| 继续经营 | 读取浏览器本地存档 |
| 瞬间图鉴 | 流通历史、解锁、形态擅长标签 |
| 设置 | 气息提示、减少动效、教程标记 |
| Esc | 多数子页返回主菜单 |

## 系统说明

- **匹配**：标签与形态擅长越重合，品质越高。
- **赠予**：比上架多 1 点温存。
- **连心**：连续做出精致/珍稀品质会获得额外温存；素简会中断。
- **日事件**：第 2 日起可能出现特供客人。

## 常见问题

- **继续经营灰色**：尚无存档，请先完成至少一次会自动保存的经营操作。
- **没有声音**：当前版本默认静音可玩，音频规格见 `docs/AUDIO_DIRECTION.md`。
