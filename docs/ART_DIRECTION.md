# 美术方向（ART_DIRECTION）

## 视觉主题

「午后书店角落里的情绪小铺」——克制、留白、温暖但不煽情。

## 风格关键词

小清新、文艺、宣纸感、柔光、手账、雾面、低对比插画

## 主色板

| 名称 | Hex | 用途 |
|------|-----|------|
| 米白 paper | `#F7F3EC` | 背景 |
| 雾绿 mist | `#A8C3B0` | 主强调 |
| 深苔 ink | `#3D4F44` | 正文 |
| 浅藕粉 blush | `#E8D0CB` | 次强调、情绪高光 |
| 暖灰 warm-gray | `#8A847A` | 次要文字 |
| 茶金 tea-gold | `#C4A574` | 稀有品质点缀 |

## 辅助色

- 花：`#D4A5B0`
- 茶：`#B8956C`
- 画：`#7BA3B8`
- 音乐：`#9B8EC4`
- 物件：`#C9B89A`

## 光照

- 侧前柔光，阴影低对比（近似 ambient occlusion 轻描）
- 避免霓虹、高饱和赛博色

## 材质

- 纸张颗粒、布面、陶瓷哑光、干花
- UI 卡片可有轻微纸质纹理（CSS 或轻贴图）

## 角色比例

- 半身/胸像为主；头身比约 1:4–1:5，偏插画而非写实

## 轮廓语言

- 软圆角、细描边或无描边色块；避免硬核像素风作为主风格

## UI 视觉语言

- 大留白、少边框、按钮如便签
- 字号层次清晰；正文 ≥ 14px 等效

## 图标规范

- 线性 + 轻填充；统一 2px 视觉线宽（导出时按 64/128）
- 五种形态图标必须可辨识且色相可区分

## 场景规范

- 店内固定机位优先；背景层次：墙 → 架 → 台 → 前景道具

## 禁止元素

- 血腥、恐怖惊吓、强闪烁、未授权 IP、廉价 clipart 拼贴感

## 一致性检查

- 对照主色板抽查截图
- 同一角色多状态保持发型/配色锚点
- 新资产入库 `docs/ASSET_MANIFEST.md`
