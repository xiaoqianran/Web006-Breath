# 已知限制与未来工作

## 已知限制

1. **音频**：已有原创 WAV（HybridAudioBus + 程序化回退）；BGM 为短循环合成琶音，非长曲真人演奏。
2. **长时性能**：未做内存泄漏与 30 分钟挂机测试（标记待测）。
3. **移动端**：有基础响应式，未做全面真机适配与触控手势。
4. **内容体量**：14 条情绪 + 5 日剧本，叙事深度有限。
5. **多语言**：仅简体中文。
6. **1000 轮框架**：长期自治目标；单次会话完成可演示原型而非全部 1000 轮。

## 未来工作（建议顺序）

1. 更长 BGM / 可选 ambience 层与音量滑条
2. 无障碍：屏幕阅读器完整文案、焦点陷阱深化
3. 内容编辑器 / JSON 热加载
4. M2 随机订单与定价系统扩展
5. 打包分析与 Lighthouse 实测写入报告（真实数据）
6. 答辩录屏与演示包一键脚本

## 非目标

- 联网多人、内购、未授权 IP、伪造用户研究数据
