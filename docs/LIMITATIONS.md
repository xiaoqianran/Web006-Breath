# 已知限制与未来工作

## 已知限制

1. **音频**：已有程序化 UI 短音（ProceduralAudioBus）；仍无外部 BGM/SFX 资源文件。
2. **长时性能**：未做内存泄漏与 30 分钟挂机测试（标记待测）。
3. **移动端**：有基础响应式，未做全面真机适配与触控手势。
4. **内容体量**：14 条情绪 + 5 日剧本，叙事深度有限。
5. **多语言**：仅简体中文。
6. **1000 轮框架**：长期自治目标；单次会话完成可演示原型而非全部 1000 轮。

1. 接入 CC0/原创音频并接通 AudioBus
2. 客人好感持久化与再访事件
3. 内容编辑器 / JSON 热加载
4. 无障碍：屏幕阅读器完整文案、焦点陷阱
5. 打包分析与 Lighthouse 实测写入报告（真实数据）
6. 答辩录屏与演示包一键脚本
