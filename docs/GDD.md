| 字段 | 内容 |
|------|------|
| 项目名 | 一息（Yixi） |
| 英文副标 | Gentle Moments Shop |
| 类型 | 叙事向经营 / 轻益智 / 情绪流通模拟 |
| 目标受众 | 喜欢治愈、文艺、慢节奏体验的玩家；毕业设计评审 |

## 1. 一句话卖点

在「一息」小店里，把客人交来的小情绪，变成一朵花、一杯茶、一幅画、一段旋律或一件小物，再流通给需要它的人。

## 2. 体验支柱

1. **温柔**：节奏慢、文案克制、反馈柔和。
2. **匹配**：情绪 × 容器形态的相性是核心决策乐趣。
3. **流通**：商品不是终点；被买走/被赠予才完成循环。
4. **记忆**：每次流通留下「瞬间卡片」，形成叙事收集。

## 3. 核心玩法循环

```
接待 → 倾听/读信 → 选择形态 → 转化 → 上架/赠予 → 结算温存 → 下一位
```

### 3.1 情绪（Emotion）

每条情绪包含：

| 字段 | 说明 |
|------|------|
| id | 唯一 ID |
| text | 客人原话/纸条文案 |
| tags | 情绪标签集合（1–3 个） |
| intensity | 1–5 强度 |
| guestName | 可匿名 |

**基础标签池**：想念、释然、疲惫、悸动、遗憾、安心、期待、孤独、温柔、勇气

### 3.2 容器形态（Vessel）

| 形态 | 擅长标签 | 气质 |
|------|----------|------|
| flower（花） | 想念、温柔、期待 | 被看见、被记得 |
| tea（茶） | 疲惫、安心、释然 | 慢下来、被安抚 |
| art（画） | 遗憾、孤独、悸动 | 说不出口的话 |
| music（音乐） | 孤独、想念、勇气 | 陪伴而不打扰 |
| object（小物件） | 安心、期待、温柔 | 随身携带的安心 |

### 3.3 转化规则（简化可测版）

- 标签与形态擅长标签每重合 1 个：+2 匹配分
- 强度 4–5 且形态匹配 ≥1：额外 +1
- 匹配分 ≥4：品质 `rare`；≥2：`fine`；否则 `simple`
- 流通价值 = 基础 1 + 匹配分 + 品质加成

### 3.4 连心（品质连击）

- 连续 `fine` / `rare` 流通会使 `qualityStreak` 递增
- `simple` 品质清零连心
- 连心 ≥2 时额外温存 `min(streak-1, 3)`

### 3.5 胜负与进度

- **无硬性失败**：可失败单次匹配，但不 Game Over
- **日目标**：完成 N 次流通 / 达到温存阈值
- **长期**：解锁客人图鉴、配方、店面装饰、特殊瞬间、日事件特供

### 3.6 日事件

- 第 2 日起 `getDayEvent(day)` 可能插入特供客人至队列头部
